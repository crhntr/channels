# channels [![Go Reference](https://pkg.go.dev/badge/github.com/crhntr/channels.svg)](https://pkg.go.dev/github.com/crhntr/channels)

Generic Go channel utilities for common concurrency patterns: fan-in, fan-out, map, filter, batch, take, and worker pools.

See the [package documentation](https://pkg.go.dev/github.com/crhntr/channels) for API details and runnable examples.
